# Implementation guardrails

Status: `SOURCE_DERIVED` synthesis of source guardrails; operational wording is `PROJECT_CONSTRAINT`. Original source tags, uncertainty and approval status remain unchanged. These rules constrain future science data and implementation; this phase implements no runtime or Scale Spine.

A guardrail is a forbidden inference paired with a required model treatment. It is not an instruction to animate the example now. Reviewers should trace each rule to the cited chapter sections and check future state transitions, material bookkeeping, metadata and observables against it. Unknown evidence is a hold, not a default. Numerical/terminological disputes remain in the [conflict register](cross_chapter_conflicts.md).

142 grouped guardrails below consolidate repeated constraints across all 20 chapters, including experimental and analytical boundaries. Each grouped rule can cover several source prohibitions without treating them as new biological laws.

## Coverage and interpretation

The early chapter guardrails are distributed among evidence conventions, hard chemistry rules, protein rendering/kinetics rules, chromosome continuity rules, replication/repair rules and gene-regulation/evolution constraints. Chapters 10–20 also supply consolidated do-not-overinterpret registers, cited throughout. Quantitative methodology adds context, significant-digit, real/display and clock requirements; its fidelity/noise section distinguishes biological randomness from cinematic agitation.

The grouped rules intentionally preserve source scope. For example, a source K+ channel, conventional kinesin, skeletal muscle, rod photoreceptor, mammalian crypt or bacterial repair pathway is not every family member. Source-era statistics and schematic models remain restricted even when the same topic appears repeatedly. Display omission never supplies biological absence; a render-only field never supplies a causal dependency.

When adding a future event, identify which rules it touches, its canonical participants/process, source claims, quantitative context and any open conflict. A valid event states a change in biology or explicitly branched assay material. A view transition only changes what is observed. This distinction also applies when no geometric mesh is visible.
