# Causal dependency graph

Status: `SOURCE_DERIVED` scientific scaffold. Graph syntax, node namespaces and interpretation rules are `PROJECT_CONSTRAINT`. This file specifies biological dependencies and source limits; it creates no WorldState instance, executable solver, renderer or clock.

## Graph contract

The graph is directed and can contain feedback. It is not assumed to be acyclic or a universal chronological schedule. `E.*` and `P.*` nodes resolve to registry definitions; `S.*` are predicates over future instances, and `G.*` are AND gates over named necessary predicates. Neither predicates nor gates are physical objects. A node's text is a condition/property definition, not an assertion that it is currently true.

```yaml
edge:
  id: D.nnn
  from: E.id | P.id | S.id | G.id
  to: E.id | P.id | S.id | G.id
  relation: typed_relation
  effect: source_qualified_change_or_requirement
  applicability: organism_cell_state_compartment_phase_assay
  source_locators: []
  source_status: inherited_without_promotion
  synthesis_status: SOURCE_DERIVED
  quantitative_bindings: context_selected_Q_ids_or_unspecified
  uncertainty: source_context_and_missing_mechanism
  sufficiency: not_asserted
```

An AND gate requires all inputs to be true; unknown input blocks execution rather than becoming false or silently assumed true. An enabling edge states a prerequisite or source-supported causal contribution, never sufficiency by itself. `component_event` means composition, not a second event that repeats material changes. `provides_substrate`, `energy_coupling`, `carrier_regeneration`, `changes`, `inhibits`, `regulates`, `spatial_guidance` and `lineage_contribution` cannot be reduced to one generic arrow.

State-changing effects require participant instance IDs, material/compartment accounting and BiologicalTime. Quantitative choices follow [bindings](quantitative_bindings.md); open [conflicts](cross_chapter_conflicts.md) constrain use. `decreases_degradation` can increase abundance without creating molecules directly. Kinase/GEF/GAP names do not determine edge sign without their target context. Cycles must retain event delays and supported kinetics; no zero-time feedback loop is implied.

For machine conversion, preserve table IDs and split compound effects into qualified claims. Do not scrape a chapter citation into a universal constant. This is a causal backbone covering the major cross-chapter couplings, not an exhaustive elementary-reaction network; the process registry also holds details and explicitly incomplete mechanisms.

## Structural relationships are not causal transitions

Containment, part-of and adjacency live in the entity records. For example, a nuclear pore is part of the nuclear-envelope system; that relation does not imply import is happening. A microtubule near cargo does not establish motor engagement. A mitochondrion touching ER does not establish luminal mixing. Parent and daughter organelle/network IDs record fission/fusion lineage; object count changes do not prove mass or function changed proportionally.

## Timing, noise and feedback

The graph preserves source time distinctions: receptor occupancy can precede fast protein-state changes and slower transcription/protein-abundance/behavior changes. Motor transport depends on track distance and motor state; diffusion uses a stochastic distance-dependent model. Cell-cycle and tissue-renewal loops are distinct. Survival/death feedback and clonal selection need actual state/lineage histories. Quantitative canon noise classes are allowed metadata, not permission to invent probabilities.

No graph edge originates at camera motion, clipping, opacity, visibility, active LOD, fluorescent color or playback duration. These cannot mutate biological state. Assay copy production is explicitly scoped to experimental material; an AnalysisState association cannot be substituted for a source-supported causal edge.
