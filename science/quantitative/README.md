# The Seamless Cell — Quantitative Canon

The 20 chapter canons answer **what exists, where it is, and what happens**.

This directory answers the complementary questions:

```text
HOW BIG?
HOW MANY?
HOW CONCENTRATED?
HOW FAST?
HOW LONG?
HOW STRONG?
HOW ACCURATE?
```

The quantitative layer is organized by physical quantity rather than textbook chapter.
