# Canonical processes

The chapter canons are sources for a shared biological model. This registry defines 203 canonical process definitions across 13 organizational categories. Category files are navigation, not separate biological worlds.

The count includes primitives, patterns, composite pathways, regulatory transitions, lineage changes and explicitly experimental material transformations. Composite and child processes are not independent events to execute twice. Analytical results such as RNA-seq counts, GWAS associations and sequence alignments are outside the native process inventory.

Aliases such as protein synthesis → translation, TCA/Krebs cycle → citric acid cycle and vesicle fusion → membrane fusion resolve to the same definition. Specialized processes reference the same underlying mechanism while retaining their distinct biological context. Missing kinetics, probabilities, regulators or balanced chemistry block execution of the affected mechanism until evidence is supplied.
