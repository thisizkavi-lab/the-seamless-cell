# Canonical entities

The chapter canons are sources for a shared biological model. This registry defines 405 canonical entity concepts across 8 organizational categories. Category files are navigation, not separate biological worlds.

Status: `SOURCE_DERIVED` synthesis draft at source baseline `48c8bb9`; schema and identity conventions are `PROJECT_CONSTRAINT`. Original chapter approval states remain unchanged.

A type is defined once but can have many instances. Molecular forms, membrane sides, roles, assembly membership and lineage are explicit; family and component inventories cannot be added to their members. State-profile records apply to an existing cell. They do not create another cell.

Records collect evidence-backed definitions and limitations. They do not select a universal reference cell, assign parameters, approve structures, or create a renderer. Names omitted from this bounded registry may be added only through a source-backed claim and an identity/deduplication check.
